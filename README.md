# CounterStreak

A small offline-first PWA for habit counters that reset on a schedule and build streaks.

- **Multiple counters**, each with its own name, goal, and reset period (minute / hour / day / week / month / year).
- **Count up or down** — a positive goal counts up to the target; a negative goal counts down from its absolute value to 0.
- **Streaks** — every period the goal is met bumps the streak; a missed period breaks it. A broken streak can be restored once during the following period (a "streak freeze").
- **Works offline** — a service worker precaches the app shell, and all state lives in `localStorage`. No server, no account.

State is persisted locally and reconciled against the wall clock on open, on tab focus, and once a second while open, so counters reset and streaks update even if the app was left running across a period boundary.

## Tech

SvelteKit (Svelte 5 runes) prerendered to static files via `@sveltejs/adapter-static`.

## Develop

```sh
npm install
npm run dev        # dev server (add -- --open to open a browser)
npm run check      # type-check with svelte-check
npm run build      # static production build
npm run preview    # preview the production build
```

App icons are generated by `node scripts/gen-icons.mjs` (writes `static/icon-{192,512}.png`).
